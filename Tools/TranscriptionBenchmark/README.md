# 听写架构对照评测

独立命令行工具，复用应用中的分段、转录、文字拼接与整理代码。不会启动应用、开启麦克风、自动插入文字或改写恢复记录。

## 测试方式

五份匿名音频，每份两轮。固定使用代码默认的识别与整理模型、语言、词典和 faithful 模式；不读取用户自定义设置。整段与分段的执行先后在两轮间交换，第二轮同时反转样本顺序。

- **整段**：逻辑停止后一次提交完整 WAV，然后整理文字。
- **分段**：以录音实际时间逐步释放音频，使用生产 `AudioChunker`，请求按生产流程串行依赖；全部成功后整理文字。
- **混合**：共享同一分段试验；识别发生错误或返回空文字时，停止后追加一次完整音频请求，再整理文字。这是故障兜底原型，不包含真正的实时会话或超时竞争。

主要计时从录音停止到识别或整理完成，不含麦克风、界面、粘贴和恢复文件读写。混合没有触发兜底时复用分段测量，不能把三列当作独立重复实验。非空结果仅表示流程完成，文字质量需另行核对原稿。

样本包含约 12 秒短句、47 秒多约束指令、117 秒含跨段改口的长指令、8 秒正文加 58 毫秒尾噪，以及纯噪声。时长依赖本机语音；生成器复用已存在的匿名短/中样本，其他样本由 macOS Tingting 合成。音频 SHA-256 与文字原稿随评测保存。

## 运行

仅准备音频、编译并验证分段，不读取密钥也不请求模型：

```sh
python3 script/benchmark_transcription.py --prepare-only
```

运行付费对照：

```sh
python3 script/benchmark_transcription.py --run
```

读取已有 OpenRouter Keychain 条目，在内存中通过标准输入交给评测程序。密钥不会进入命令参数、报告或日志。报告默认写到 `/tmp/opentypeless-benchmark-20260925/results.json`，已有报告时拒绝覆盖，以免重复调用；经确认需要重测时可指定新的 `--report` 路径。

单次运行最多预约 90 次请求，已返回的已知费用达到 0.50 美元后不再启动新请求。失败响应或缺失的 usage 不可计费为零，因此该费用阈值不是最终账单的硬上限。没有自动重复试验；中断后已有完整试验写入报告，正在执行的试验可能没有持久化。

离线汇总完整报告，不产生模型调用：

```sh
python3 script/summarize_transcription_benchmark.py /tmp/opentypeless-benchmark-20260925/results.json --output /tmp/opentypeless-benchmark-20260925/summary.json
```

两轮只是初步筛选，不能据此估计真实用户总体准确率、稳定的 P95 或确定最佳分段阈值。真人口音、嘈杂环境、弱网、取消和恰好一次插入仍需后续专项验收。
